**Project description:**

The problem we have identified is that many people spend a lot of time on their phones. We want to find a way to help people use their phones effectively and efficiently without wasting excessive time on certain apps - for example, social media applications. We would like to create an application or software that helps prevent endless scrolling, for example by blocking access or limiting time. However, the specific implementation will depend upon insights revealed through interviews.

We plan to interview mobile phone users and investigate app usage, emotions relating to scrolling, overall satisfaction with time spent on the phone, etc. Based on our findings, we will design an app that addresses interviewee concerns. This problem affects most people, so we hope to find a solution that is widely effective.
